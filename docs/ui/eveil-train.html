Maquette de discussion pour le panel (orthophonistes, parents, spécialistes du développement). Un wagon par syllabe orale, le fourgon de queue pour la consonne finale. Les lettres sont pour l'adulte : l'enfant lit les couleurs. Règle d'or : on ne montre une partie manquante que si l'écoute en est sûre.

En direct, pendant que l'enfant parle (« minouche »)

  1. 0,28 s — parole détectée : l'oreille de la mascotte s'allume
  2. 0,39 s — 1ʳᵉ syllabe entendue : le wagon « mi » s'allume
  3. 0,72 s — 2ᵉ syllabe : le wagon « nou » s'allume
  4. 0,77 s — friction finale : le fourgon « ch » s'accroche
  5. 1,75 s — fin d'énoncé (silence) : verdict final, la fête
